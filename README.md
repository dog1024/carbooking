# 顺风车出行板



## 功能

- 所有访问者共享查看同一份行程
- 登记司机称呼、出行日期与时间、出发地、途经地点、终点、可载人数、剩余人数、联系方式、乘车费用和备注
- 按出行日期从新到旧排列，并实时同步其他访问者的新增和修改
- 行程发布后不能删除，只有发布者可以调整剩余座位
- 创建超过 7 天的记录自动变更为 `expired` 状态并从页面隐藏，数据库保留历史数据
- 支持将旧版本的浏览器本地记录迁移到共享列表
- 页面包含非营利用途及出行安全免责声明
- 适配电脑和手机屏幕

## 数据库升级

如果 Supabase 项目已经运行过旧版脚本，请在 SQL Editor 中重新运行当前的 [`supabase/schema.sql`](supabase/schema.sql)。脚本会保留现有记录、增加乘车费用和备注字段、撤销发布者的删除权限，并将原来的物理删除任务替换为每分钟更新过期状态的任务。旧记录没有费用时会显示“待确认”。
